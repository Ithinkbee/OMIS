# Финансовая Аналитическая Платформа

## Описание проекта

Это настольное приложение для анализа финансовых рынков, управления инвестиционными портфелями и автоматизации торговли. Система поддерживает разделение ролей и предоставляет инструменты для прогнозирования цен и генерации отчетов.

Приложение реализовано на **Python** с использованием библиотеки **Tkinter** для графического интерфейса и **SQLite** для хранения данных.

---

## Основные возможности

1. **Аутентификация и Роли**
   - Регистрация и вход в систему.
   - Роли: **Инвестор** (торговля, боты), **Аналитик** (прогнозы, обучение моделей), **Менеджер** (администрирование, отчеты).

2. **Дашборд и Торговля**
   - Мониторинг котировок в реальном времени (симуляция).
   - Покупка и продажа активов.
   - Просмотр текущего состава портфеля и истории изменений.

3. **Прогнозирование и Анализ**
   - Построение прогнозов цен (ARIMA, LSTM, Random Forest).
   - Генерация рекомендаций (Buy/Sell/Hold) на основе анализа данных.
   - Обучение новых моделей анализа (только для Аналитиков).

4. **Автоторговля**
   - Создание торговых ботов с параметрами (Stop-Loss, Take-Profit, Max Position).
   - Запуск цикла выполнения торговых стратегий.

5. **Отчетность**
   - Генерация отчетов по портфелю (доходность, волатильность, VaR, Stress Test).

6. **Администрирование**
   - Просмотр и принудительное редактирование портфелей пользователей (только для Менеджеров).

---

## Технические детали

- **Язык:** Python 3.x.
- **База данных:** SQLite (`finance_platform.db`).
- **Архитектура:** MVC (Model-View-Controller) с использованием Dependency Injection.
- **UI:** Tkinter (Standard Library).
- **Особенности:** Многопоточность для мониторинга рынка, реализация паттернов Repository и Command.

## Сценарии демонстрации системы

### 1. **Регистрация и Торговля (Инвестор)**
1. Зарегистрируйтесь как "Investor".
2. На вкладке **Dashboard** выберите актив и нажмите "Buy". Введите количество.
3. Убедитесь, что актив появился в таблице "My Favorites / Wallet".

### 2. **Прогнозирование (Аналитик/Менеджер)**
1. Войдите как "Analyst".
2. Перейдите на вкладку **Forecasting**.
3. Выберите актив и модель (например, LSTM).
4. Нажмите "Generate Forecast". Система отобразит график с прогнозом и торговую рекомендацию.

### 3. **Настройка автоторговли**
1. На вкладке **AutoTrading** заполните форму: имя бота, стратегия, актив, риски (SL/TP).
2. Нажмите "Deploy Bot". Бот появится в списке ниже.
3. Нажмите "Run Execution Cycle" для симуляции работы ботов.

## Структура проекта

- `entry_point.py` — Точка входа, конфигурация зависимостей и запуск приложения.
- `database_setup.py` — Инициализация и первичное наполнение БД (Seed data).
- `model.py` — Сущности (User, Asset, Portfolio) и Репозитории (SQL запросы).
- `control.py` — Бизнес-логика (Контроллеры авторизации, торговли, анализа).
- `representation.py` — Графический интерфейс (Окна, виджеты, обработка событий).
- `infrastructure.py` — DI-контейнер и фабрики для связывания компонентов.
